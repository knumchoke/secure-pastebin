## Rules for every agent

1. **Branch per workstream:** `ws1-foundation`, `ws2-crypto-paste`, … Rebase on `main` before opening a PR.
2. **Contracts are frozen after WS1.** If you must change `internal/*/ports.go`, `internal/paste/types.go`, `internal/config`, migration `0001`, or `docs/api/openapi.yaml`, add an entry to `docs/api/CHANGELOG.md` and say so in your PR description. Prefer *adding* over changing.
3. **TDD.** Every task: failing test → run → implement → run → commit. Commit messages: `feat(ws2): …`, `test(ws2): …`, `chore(ws1): …`.
4. **Shell prefix:** this workspace uses `rtk` — run `rtk go test ./...`, `rtk git status`, etc.
5. **Never log or print** paste content, passwords, session IDs, CSRF tokens, challenge tokens, or key material. Tests may use fixed test vectors.
6. **No new third-party dependency** beyond the list in each plan's Global Constraints without noting it in the PR.
7. Definition of done for a plan = every checkbox ticked, `make check` green, PR opened against `main` with the plan's "Done when" list pasted in.

## Shared toolchain

- Go 1.25 (`go.mod` says `go 1.25`), `golangci-lint`, `govulncheck`
- Node 22 + npm for `ui/`
- Docker + Docker Compose v2 (integration tests use `testcontainers-go`; needs a Docker socket)
- `make check` = `go vet ./... && golangci-lint run && go test ./... && (cd ui && npm test)`

### Review matrix — nobody reviews their own work
- Codex (WS2, WS3) → Claude security review (`/security-review`, `/code-review`).
- Claude (WS1, WS5) → Codex review (`codex:rescue` review mode or a Codex session over the PR diff).
- Antigravity (WS4, WS6, WS7 e2e) → Claude (CSP/XSS, headers) + Codex second pass on jigsaw geometry.
